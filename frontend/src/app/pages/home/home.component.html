How AgriDisha Operates

A modern, resilient decoupled microservice architecture

1
Input Data

Enter soil N-P-K parameters or upload a leaf photo in the Angular frontend.

2
Spring Boot Gateway

Spring Boot validates inputs, integrates OpenWeatherMap, and secures requests.

3
FastAPI Inference

Python ML service evaluates XGBoost/Random Forest and PyTorch ResNet9 models.

4
Actionable Output

Get crystal-clear crop selections, fertilizer dosages, and plant treatment guides.
